# Features

- Premium green, cream and muted-gold visual system
- Mobile-first responsive layout with desktop navigation and mobile drawer
- Lightweight branded loading transition and scroll reveal motion
- Product categories and live text search
- Demonstration product catalogue with explicit sample price labels
- Cart quantity controls, removal, estimated subtotal and localStorage persistence
- Checkout details form and formatted WhatsApp order enquiry
- Contact enquiry form with WhatsApp/clipboard hand-off
- Google Maps search link with exact-pin verification note
- Delivery coverage caveat and FAQ accordion
- SEO metadata, JSON-LD starter schema, robots.txt and sitemap
- Keyboard Escape handling, form labels, focus styles and reduced-motion support
